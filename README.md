# Нейро-стенографист

Локальное преобразование аудиозаписей в структурированную расшифровку с разделением
говорящих. Все вычисления выполняются на Android-устройстве, без доступа к интернету.

**Хакатон:** Nuclear IT Hack 2026 · **Команда:** Hex.Team

---

## Что делает

Принимает запись разговора из памяти устройства, распознаёт речь, определяет кто говорит,
расставляет временные метки и экспортирует результат в JSON.

```
Аудиофайл → Распознавание речи → Определение говорящих → Сшивка → Пунктуация → JSON
```

## Сборка

Требуется JDK 17 и Android SDK (compileSdk 35).

```bash
cd android
./gradlew assembleDebug      # APK → app/build/outputs/apk/debug/app-debug.apk
./gradlew test               # юнит-тесты ядра
./gradlew assembleRelease    # релизная сборка
```

Путь к SDK задаётся в `android/local.properties`:

```properties
sdk.dir=/path/to/android-sdk
```

---

## Запуск

1. Установить APK на устройство (Android 8.0 и выше).
2. Выбрать аудиофайл из памяти устройства.
3. Нажать «Распознать».
4. Экспортировать результат в JSON или текстом.

В debug-сборке включены заглушки движков: приложение полностью работает без моделей
и без сети. Это позволяет проверять интерфейс и экспорт параллельно с разработкой моделей.

## Контракты данных

| Функция | Вход | Выход |
|---|---|---|
| `transcribe(path)` | аудиофайл | `[{start_ms, end_ms, text}]` |
| `diarize(path)` | аудиофайл | `[{start_ms, end_ms, speaker}]` |
| `merge(segments, speakers)` | результаты двух предыдущих | реплики «кто, когда, что» |
| `clean(text)` | текст реплики | текст с пунктуацией |

Подробно — в `docs/PROTOCOL.md`.

---

## Формат результата

```json
{
  "transcript": [
    {
      "speaker_id": "speaker_1",
      "start_ms": 1250,
      "end_ms": 4380,
      "text": "Добрый день!"
    }
  ]
}
```

## Офлайн-гарантия

Приложение **не запрашивает разрешение `INTERNET`**. Это проверяется на собранном APK:

```bash
aapt2 dump permissions app-debug.apk
```

В списке разрешений интернета нет — приложение физически не может обратиться к сети.
