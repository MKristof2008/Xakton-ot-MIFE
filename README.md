# Xakton-ot-MIFE — Нейро-стенографист

**Кейс:** Hex.team, Nuclear IT Hack 2026 (осень)

**Задача:** Android-приложение для локальной транскрибации аудио с диаризацией.

## Что нужно от команды

По `TZ_FOR_TEAM.md` — 6 компонентов:

1. **ASR** (`asr.py`) — faster-whisper, локально
2. **Диаризация** (`diarization.py`) — pyannote/speechbrain
3. **LLM** (`llm.py`) — llama.cpp + Gemma-2B
4. **Формат** (`output.py`) — JSON по ТЗ
5. **Метрики** (`metrics.py`) — WER, RTF, DER
6. **Android** (`android/`) — Kotlin + JNI
