# Нейро-стенографист

Локальное преобразование аудио- и видеозаписей в структурированную расшифровку
с разделением говорящих. **Все вычисления выполняются на Android-устройстве,
без доступа к интернету.**

**Хакатон:** Nuclear IT Hack 2026 · **Команда:** Hex.Team

---

## Что делает

Принимает запись разговора из памяти устройства, распознаёт речь, определяет кто
говорит, расставляет временные метки, восстанавливает пунктуацию и экспортирует
результат в JSON.

```
Аудио или видео → Декодирование → Распознавание речи → Определение говорящих
    → Сшивка реплик → Пунктуация (локальная LLM) → JSON
```

## Быстрый старт

### Готовый APK

**`artifacts/app-release.apk`** · 704 МБ · Android 8.0+, arm64 · файл лежит в
этом репозитории (Git LFS). Прямой ссылки на скачивание здесь нет намеренно:
APK передаётся организаторам и прикладывается к отчёту файлом.

Модели упакованы внутрь: после установки интернет не нужен ни разу.
Подробная инструкция — `docs/USER_GUIDE.md`.

### Сборка из исходников

```bash
cd android
./scripts/bootstrap.sh      # библиотеки, исходники движков, модели (~1.3 ГБ)
./gradlew :app:test         # юнит-тесты
./gradlew :app:assembleRelease
./scripts/install_apk.sh release   # установка на подключённый телефон
```

Требуется JDK 17, Android SDK (compileSdk 35), NDK 26, CMake 3.22.

## Архитектура

Пайплайн одного файла — целиком на устройстве:

```
аудио/видео (wav, mp3, m4a, ogg, aac, mp4, mkv, mov)
  → AudioConverter: MediaExtractor + MediaCodec → WAV 16 кГц моно
  → NoiseReducer: спектральное вычитание, включается только при устойчивом шуме
  → ASR: whisper.cpp (ggml-small-q5_1), окна по 30 с → сегменты с таймкодами
  → диаризация: sherpa-onnx (pyannote-3.0 + 3D-Speaker + кластеризация)
  → SpeakerPostProcess: склейка пауз, деление пауз между говорящими
  → Merge: реплика делится по смене говорящего только на границе предложения
  → локальная LLM: llama.cpp + Qwen2.5-0.5B (Q4_K_M), только пунктуация
  → JSON по схеме ТЗ
```

**Модели на устройстве:**

| Этап | Модель | Размер | Лицензия |
|---|---|---|---|
| Распознавание | whisper small q5_1 (ggml) | 181 МБ | MIT |
| Сегментация речи | pyannote segmentation-3.0 (ONNX) | 6 МБ | MIT |
| Отпечатки голоса | 3D-Speaker ERes2Net (ONNX) | 38 МБ | Apache-2.0 |
| Пунктуация | Qwen2.5-0.5B-Instruct Q4_K_M (GGUF) | 469 МБ | Apache-2.0 |

Почему выбраны именно эти — `docs/ML_MODELS.md`.

## Офлайн-гарантия

Это не обещание, а техническое свойство:

- в манифесте release-сборки **нет разрешения `INTERNET`**
  (проверено `aapt2 dump permissions`);
- в собранных `.so` **нет сетевых вызовов** — проверено символами линкера
  (`connect`, `socket`, `getaddrinfo`, `curl` отсутствуют);
- в коде приложения нет HTTP-клиентов, аналитики и краш-SDK;
- модели лежат внутри APK, сеть нужна только при сборке.

Приложение проверено в авиарежиме: импорт, распознавание, диаризация и экспорт
работают полностью.

## Контракты данных

| Функция | Вход | Выход |
|---|---|---|
| `transcribe(path)` | аудиофайл | `[{start_ms, end_ms, text}]` |
| `diarize(path)` | аудиофайл | `[{start_ms, end_ms, speaker}]` |
| `merge(segments, speakers)` | результаты двух предыдущих | реплики «кто, когда, что» |
| `clean(text)` | текст реплики | текст с пунктуацией |

Подробно — `docs/PROTOCOL.md`.

## Формат результата

```json
{
  "transcript": [
    {
      "speaker_id": "speaker_1",
      "start_ms": 1250,
      "end_ms": 4380,
      "text": "Добрый день!"
    }
  ]
}
```

Ровно четыре поля на реплику, целые миллисекунды, порядок по `start_ms`,
`end_ms >= start_ms`, UTF-8 без escape-мусора. Проверяется тестом `ExportTest`
и сквозным `PipelineE2ETest`.
