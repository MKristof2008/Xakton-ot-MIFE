## Слайд 3 — Решение

# Всё считается на телефоне

Четыре движка на устройстве:

| Этап | Что делает |
|---|---|
| ⬡ **ASR** | Речь → текст (Whisper, whisper.cpp) |
| ⬡ **Диаризация** | Кто говорит (sherpa-onnx) |
| ⬡ **Сшивка** | Реплики + временные метки |
| ⬡ **LLM** | Протокол: темы, решения, задачи (llama.cpp) |

**0** разрешений INTERNET в релизе. **0** байтов уходит в сеть.
