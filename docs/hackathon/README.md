# Nuclear IT Hack 2026 — сводка по проекту «Нейро-стенографист»

Документы по хакатону: официальное ТЗ, задачи интегратора, контракты данных,
аудит репозитория. Собрано и приведено в соответствие с официальной презентацией
организаторов.

**Дата сборки:** 6 ноября 2026. Интегратор: Фатеев Фёдор.

---

## Главное

1. **Официальное ТЗ — Android-приложение с локальными моделями, полностью офлайн.**
   Запрещены облачные API, удалённые вычисления и передача аудио наружу
   (презентация, слайды 8–11).

2. **Обучения модели с нуля ТЗ не требует.** Слайд 11: «Использование готовых моделей
   и библиотек допускается». Слайд 13: участники сами выбирают модели, архитектуру
   и способы интеграции. Слайд 12: важно понимание решения, а не факт наличия ИИ.
   Критерии оценки — про результат (WER 40, DER 25, таймкоды 10, RTF 10, UX 10,
   защита 5), а не про происхождение весов.

3. **`neuro_stenographer_team.pdf` расходится с официальным ТЗ:** там веб-приложение
   на Streamlit с облачным API. Официальная презентация главнее — по ней оценивают.

## Что сделано в репозитории

1. **Android-платформа зафиксирована:** Kotlin + Jetpack Compose вместо Python + Streamlit.
2. **Структура по шаблону организаторов:** `docs/`, `artifacts/`, `config/`, `src/`.
3. **Контракты данных реализованы:** `transcribe`, `diarize`, `merge`, `clean` + экспорт JSON.
4. **Метрики WER/DER/RTF** написаны и покрыты тестами.
5. **APK собирается**, разрешение `INTERNET` отсутствует — офлайн гарантирован технически.
6. **Сайт-витрина** в `site/`.
7. **Python-пайплайн с локальными моделями:** `asr.py` (faster-whisper WER 0.161),
   `diarization.py`, `metrics.py`, `output.py`, `run_local.py`.
