# Сценарий демо-видео (2–3 минуты, режим полёта)

Цель ролика — показать выполнение всех пунктов ТЗ на реальном устройстве без сети.

## Подготовка (до записи)

1. Установленный APK, модели на устройстве (см. docs/USER_GUIDE.md).
2. 2–3 тестовых аудиофайла (диалоги на русском) в памяти устройства.
3. Включён режим полёта — показать иконку в шторке в первом кадре.

## Хронометраж

**0:00–0:20 — Оффлайн и запуск.**
Показать включённый режим полёта (шторка), запустить приложение.
Заодно можно показать системный экран «О приложении» → разрешения: нет интернета.

**0:20–0:40 — Импорт.**
«Выбрать файл» → системный выбор → тестовый диалог. Показать выбранный файл.
(Опционально: коротко показать запись с микрофона — 5–10 секунд живой речи.)

**0:40–1:20 — Обработка.**
«Обработать». Крупно: смена этапов конвейера, прогресс. На 10-й секунде свернуть
приложение, показать уведомление о работе в фоне, вернуться. Дождаться результата.
(Длинные участки ускорить монтажом, RTF потом озвучить по экрану метрик.)

**1:20–2:00 — Результат.**
Лента реплик: цвета говорящих, метки `[ММ:СС]`. Показать:
поиск по слову; фильтр по говорящему; долгое нажатие → переименование «Спикер 1» → «Ведущий».
Тап по реплике → плеер переходит к её началу и играет голос; текущая реплика подсвечивается.
Показать блок метрик (длительность, реплики, RTF).

**2:00–2:30 — Экспорт и проверка.**
«Экспорт» → JSON → сохранить в «Загрузки». Открыть файл в просмотрщике/проводнике,
показать структуру `{"transcript":[{speaker_id, start_ms, end_ms, text}]}`,
кириллица, целые миллисекунды, `speaker_1`/`speaker_2` (переименование не влияет на экспорт).
Показать Share → SRT/TXT.

**2:30–2:45 — Финал.**
Ещё раз шторка с режимом полёта — весь цикл выполнен без сети.

## Что нельзя показывать

- Запросы сети, включённый интернет.
- Debug-баннер «DEBUG FAKE» — ролик снимается на release-сборке.
