# Прогон 001 — ggml-small (коммит 09709dc)

## Параметры
- Модель: ggml-small.bin (~465 МБ), whisper.cpp JNI, flash_attn, 8 потоков
- Устройство: Samsung SM-S938B, CPU
- Запись: 31 488 мс (живая речь с микрофона телефона)

## Замеры
- Инференс: 517 773 мс → **RTF = 16.44** (цель < 1 — провал)

## Транскрипт (как снят из logcat)
- 2 реплики на 31.5 с записи
- Текст содержал мусорные спецтокены `[_BEG_]`, `[_TT_100]` (исправлено в cf1d643)

## Разбор ошибок
1. **Скорость**: 244M параметров на CPU телефона — RTF 16.4, непригодно.
2. **Потеря речи**: 2 реплики на полминуты записи — whisper full-сегменты
   склеиваются/теряются без VAD-чанкинга.
3. **Шум/паузы**: не анализировались отдельно — запись живого разговора,
   часть фраз явно не попала в вывод.
4. **Спикеры**: диаризации нет, все реплики без speaker_id-разделения.

## Вывод
small непригоден на этом железе → переход на ggml-base. Фильтр спецтокенов
обязателен (cf1d643).
