# Прогон 002 — ggml-base (коммит cf1d643)

## Параметры
- Модель: ggml-base.bin (~148 МБ), whisper.cpp JNI, flash_attn, 8 потоков
- Устройство: Samsung SM-S938B, CPU
- Запись: 13 568 мс (живая речь с микрофона телефона)

## Замеры
- Инференс: 79 829 мс → **RTF = 5.88** (лучше small в 2.8 раза, цель <1 не достигнута)

## Транскрипт (logcat)
```
SEG	0	7000	Как что, Брецборок, а делам? 5-я с Крышом.
```
1 реплика [0..7000 мс] на 13.5 с записи.

## Разбор ошибок
1. **Скорость**: RTF 5.88 — всё ещё в ~6 раз медленнее цели.
2. **Потеря речи**: вторая половина записи (7.0–13.5 с) не попала в транскрипт —
   whisper выдал один сегмент и обрезал остальное. Причина-кандидат: пауза/тишина
   после 7 с + отсутствие VAD-чанкинга; проверить логику детекта конца речи.
3. **Качество текста**: «Брецборок» — явная ASR-ошибка (вероятно «Братцборок»/
   искажённое имя); «5-я с Крышом» — сомнительно, похоже на галлюцинацию на шуме
   или тихой речи. Спецтокенов нет — фильтр cf1d643 работает.
4. **Пунктуация**: вопросительный знак проставлен — ок.
5. **Спикеры**: диаризации нет, один speaker на всё.

## Вывод
base не влезает в RTF<1 на CPU → переход на ggml-tiny (коммит 545a3fb) для
проверки скорости; параллельно кандидат — sherpa-onnx Zipformer/GigaAM
(быстрее Whisper на ARM) и VAD-чанкинг против потери речи.
