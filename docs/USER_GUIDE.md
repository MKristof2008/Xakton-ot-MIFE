# Инструкция по установке и использованию

Приложение «Нейро-стенографист» (Hex.Team) — локальная расшифровка аудиозаписей
с разделением говорящих. Работает без интернета: разрешение `INTERNET` не запрашивается.

## Требования

- Android 8.0 (API 26) и выше, архитектура **arm64**.
- Свободное место: **704 МБ** — модели упакованы внутрь APK.
- Процессор: Snapdragon 8-го поколения или аналог. На слабых устройствах
  обработка идёт медленнее реального времени.

## Установка

1. Скачайте APK:
   [app-release.apk](https://github.com/MKristof2008/Xakton-ot-MIFE/raw/feature/ml/artifacts/app-release.apk)
2. Скопируйте на устройство и установите (разрешите установку из источника).
3. При первом запуске модели копируются из APK в память приложения — это занимает
   несколько секунд. Интернет не нужен ни при установке, ни при работе.
4. Разрешения: микрофон (для записи) и уведомления (для фоновой обработки).
   Разрешения на интернет приложение не запрашивает — его нет в манифесте.

## Использование

1. **Выбор файла.** На главном экране: «Выбрать файл» — принимаются и **аудио**
   (mp3, wav, m4a, ogg, aac), и **видео** (mp4, mkv, mov, webm): звуковая дорожка
   извлекается на устройстве. Либо «Записать с микрофона» (m4a/AAC).
2. **Обработка.** Нажмите «Обработать». Экран показывает этапы конвейера
   (распознавание → диаризация → сшивка → LLM-постобработка) и кнопку «Отменить».
   Обработка продолжается в фоне при сворачивании (foreground service с уведомлением).
3. **Результат.** Лента реплик с цветом говорящего и временем `[ММ:СС]`:
   - поиск по тексту реплик;
   - фильтр по говорящему (чипы сверху);
   - долгое нажатие на чип говорящего — **проверка голоса по сохранённым**:
     покажет всех кандидатов с процентом сходства и кнопку «Подписать»;
   - долгое нажатие на реплику — переименование (только в отображении;
     в экспорте остаются `speaker_1`, `speaker_2`, …);
   - метрики: длительность аудио, число реплик и говорящих, RTF.
4. **Плеер.** Кнопка «Слушать» на экране результата; тап по реплике переводит
   воспроизведение к её началу, текущая реплика подсвечивается.
5. **Экспорт.** Кнопка «Экспорт»:
   - **JSON** — строгая схема ТЗ `{"transcript":[{"speaker_id","start_ms","end_ms","text"}]}`,
     сохраняется в выбранное место через системный диалог;
   - **TXT** и **SRT** — через диалог «Поделиться».

## Формат экспорта (JSON)

```json
{"transcript":[{"speaker_id":"speaker_1","start_ms":1250,"end_ms":4380,"text":"Добрый день!"}]}
```

Реплики упорядочены по `start_ms`, времена — целые миллисекунды от начала записи,
кодировка UTF-8, лишних полей нет.
