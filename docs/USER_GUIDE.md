# Инструкция по установке и использованию

Приложение «Нейро-стенографист» (SuperAI) — локальная расшифровка аудиозаписей
с разделением говорящих. Работает без интернета: разрешение `INTERNET` не запрашивается.

## Требования

- Android 8.0 (API 26) и выше.
- Свободное место: APK + модели (см. docs/ML_MODELS.md, итоговый размер TODO —
  зависит от финальной схемы хранения моделей).

## Установка

1. Скопируйте APK на устройство и установите (разрешите установку из источника).
2. Если модели поставляются отдельно от APK — скопируйте их на устройство заранее
   (схема: `filesDir/models/` через adb, см. docs/ML_MODELS.md; без сети).
3. Интернет после установки не нужен. Для проверки можно включить режим полёта.

## Использование

1. **Выбор аудио.** На главном экране: «Выбрать файл» (импорт mp3, wav, m4a, ogg, aac
   из памяти устройства через системный выбор файлов) или «Записать» (запись с
   микрофона, потребуется разрешение RECORD_AUDIO; сохраняется m4a/AAC).
2. **Обработка.** Нажмите «Обработать». Экран показывает этапы конвейера
   (распознавание → диаризация → сшивка → LLM-постобработка) и кнопку «Отменить».
   Обработка продолжается в фоне при сворачивании (foreground service с уведомлением).
3. **Результат.** Лента реплик с цветом говорящего и временем `[ММ:СС]`:
   - поиск по тексту реплик;
   - фильтр по говорящему (чипы сверху);
   - долгое нажатие на имя говорящего — переименование (только в отображении;
     в экспорте остаются `speaker_1`, `speaker_2`, …);
   - метрики: длительность аудио, число реплик и говорящих, RTF.
4. **Плеер.** Кнопка «Слушать» на экране результата; тап по реплике переводит
   воспроизведение к её началу, текущая реплика подсвечивается.
5. **Экспорт.** Кнопка «Экспорт»:
   - **JSON** — строгая схема ТЗ `{"transcript":[{"speaker_id","start_ms","end_ms","text"}]}`,
     сохраняется в выбранное место через системный диалог;
   - **TXT** и **SRT** — через диалог «Поделиться».

## Формат экспорта (JSON)

```json
{"transcript":[{"speaker_id":"speaker_1","start_ms":1250,"end_ms":4380,"text":"Добрый день!"}]}
```

Реплики упорядочены по `start_ms`, времена — целые миллисекунды от начала записи,
кодировка UTF-8, лишних полей нет.
