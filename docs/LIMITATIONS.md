# Ограничения решения

Честный список того, что работает не идеально и при каких условиях.

## Функциональные

**Заглушек в решении нет.**
Все этапы работают на настоящих моделях: распознавание, диаризация и пунктуация.
Заглушки, которые были на раннем этапе, удалены из кода полностью — их нет ни в
рабочем пути, ни в APK. Это проверено распаковкой dex release-сборки.

**Запись с микрофона — только m4a/AAC.**
Импорт из памяти устройства поддерживает любые форматы, которые умеет декодировать
MediaCodec устройства (mp3, wav, m4a, ogg, aac). Встроенная запись сохраняет
m4a (AAC) — качества достаточно для распознавания, но это не lossless.

**Экспорт в файл только для JSON, TXT и SRT — через «Поделиться».**
JSON сохраняется напрямую в файл через системный диалог выбора места.
TXT и SRT передаются в диалог «Поделиться», а не сохраняются напрямую в папку —
пользователь сам выбирает приложение для сохранения.

## Качество распознавания

**Шумные записи.**
При сильном фоновом шуме точность падает. Шумоподавление реализовано
(`NoiseReducer`: спектральное вычитание с оценкой фона и защитным floor), но
включается только при обнаружении устойчивого шума — на чистой записи сигнал
возвращается без изменений. Корректного замера «WER на шумной записи до и после»
пока нет: предыдущая попытка дала неверный baseline из-за кэширования
промежуточного WAV, поэтому цифры не публикуются.

**Длинные записи.**
Запись обрабатывается окнами по 30 секунд. Это снимает вылеты по памяти, но
на стыке окон возможна потеря одного слова, если оно приходится ровно на
границу. Перекрытие окон пробовалось и убрано: оно давало дубли фраз, которые
надёжнее не снимались.

**Перебивания.**
Когда несколько человек говорят одновременно, распознаётся только доминирующий голос.
Обработка одновременной речи — задача уровня Ultra Pro Max, в текущей версии не решена.

**Короткие реплики.**
Реплики короче ~0.5 секунды могут теряться или приписываться соседнему говорящему.

**Разница тембра.**
Диаризация хуже разделяет говорящих с похожим тембром голоса.

## Производительность

**Зависимость от устройства.**
Скорость обработки (RTF) определяется процессором телефона. На бюджетных устройствах
обработка может идти медленнее реального времени.

**Память.**
Одновременная загрузка модели распознавания и языковой модели требует значительного
объёма RAM. На устройствах с малым объёмом применяется последовательная загрузка.

## Языковая модель

**Не перефразирует.**
Модель только расставляет пунктуацию и регистр. Смысл и формулировки сохраняются —
это требование, а не ограничение.

**Не исправляет фактические ошибки.**
Если распознавание неверно поняло слово, языковая модель может не заметить ошибку,
чтобы не искажать смысл.

## Что НЕ является ограничением

- **Отсутствие интернета** — не ограничение, а требование. Приложение не запрашивает
  разрешение `INTERNET`, поэтому физически не может обратиться к сети.
- **Использование готовых моделей** — разрешено ТЗ.
- **Отсутствие облачных сервисов** — осознанное архитектурное решение.
