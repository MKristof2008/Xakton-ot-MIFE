## Технические проверки (все выполнены)

- [x] В манифесте release-сборки **нет** `android.permission.INTERNET`.
      Проверено `aapt2 dump permissions`: только RECORD_AUDIO, FOREGROUND_SERVICE,
      FOREGROUND_SERVICE_DATA_SYNC, POST_NOTIFICATIONS.
- [x] В собранных `.so` нет сетевых вызовов — проверено символами линкера:
      `connect`, `socket`, `getaddrinfo`, `curl` отсутствуют.
- [x] В коде нет HTTP-клиентов, аналитики и краш-SDK
      (okhttp/retrofit/ktor/volley/firebase отсутствуют в APK).
- [x] Заглушек нет ни в коде, ни в APK: удалены из main-исходников,
      в dex release-APK классов `Stubs*` нет (проверено распаковкой).
- [x] Экспортный JSON соответствует ТЗ: ровно 4 поля, целые миллисекунды,
      порядок по `start_ms`, `end_ms >= start_ms`, UTF-8 без escape.
      Покрыто `ExportTest` (9 тестов) и сквозным `PipelineE2ETest`.
- [x] Модели внутри APK, копируются при первом запуске; приложение работает
      без сети с первой секунды.
- [x] Приложение запущено и проверено в авиарежиме (иконка ✈ в шторке).
- [x] Обработка переживает сворачивание (foreground service) и поворот
      (состояние в ViewModel).
- [x] Длинные записи не вылетают: 10-минутный файл → 86 реплик, без `FATAL`/`OOM`.
- [x] Видео на входе: mp4/mkv/mov → извлечение дорожки на устройстве
      (69 МБ → 73 с, 126 МБ → 125 с).
- [x] Узнавание голоса между записями: свой голос 0.89–0.92, чужой 0.02–0.16.

## Что осталось сделать команде

1. **Записать демо-видео** (2–3 мин) по `docs/DEMO_SCENARIO.md` и положить в
   репозиторий. Это единственный незакрытый пункт отчёта.
2. **Прогнать три записи экспертов**, когда они появятся, и обновить таблицу
   WER/RTF реальными цифрами. Сейчас замеры на 20 записях VoxForge RU + 1 диалог.
3. **Проверить установку APK на другом устройстве** (кроме SM-S938B):
   размер 704 МБ и arm64 могут стать ограничением.
4. **Слайды для защиты** — `docs/SLIDES.md` обновлены под финальные цифры.

## Известные ограничения, о которых стоит сказать экспертам

- DER 0.082 измерен на одной записи с двумя говорящими. Для 3–4 участников
  порог кластеризации (0.9) не проверялся — вероятна недооценка числа людей.
- WER 0.178 — среднее по 20 записям VoxForge (чистая студийная речь).
  На шумных записях будет выше.
- RTF 0.31 на диалоге 80 с; на 30-минутной записи обработка займёт ~10 минут.
- Перебивания (одновременная речь) не поддерживаются: распознаётся доминирующий голос.
- Шумоподавление реализовано, но корректного замера «до/после» нет —
  поэтому не заявляется как улучшение WER.
