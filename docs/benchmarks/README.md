## Протокол
- Сборка Release, одно устройство (SM-S938B), без троттлинга, ≥3 повтора, берём медиану.
- Конфигурация = модель × квантизация × потоки × [шумодав] × [LLM].
- Мерим: WER, DER, средняя |Δstart_ms|, RTF = inference_ms / audio_ms, пик RAM, размер моделей, пустые/мусорные реплики.
- WER с нормализацией: нижний регистр, без пунктуации, ё=е (tools/, jiwer).
- DER: pyannote.metrics или dscore (сравнение с ref-таймлайном).
- Экспортный JSON валидируем по схеме ТЗ.
- Результаты — в measurements.csv, графики — tools/make_bench_charts.py.
