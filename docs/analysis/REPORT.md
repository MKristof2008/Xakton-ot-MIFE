# Отчёт о проделанной работе — зона ML (feature/ml)

Дата: 07.11.2026. Устройство тестов: Samsung SM-S938B. Все цифры — реальные
измерения (logcat телефона / pytest / WER-скрипты), источники указаны.

## 1. Что сделано (хронология, коммиты feature/ml)

### ML-пайплайн на ПК
- `a975540` — end-to-end прогон диалога 2 спикеров, WER=0.144 (whisper small);
  генератор тест-диалогов `tools/make_dialog.py`.
- `c899c12` — `tools/live_dictation.py`: запись с микрофона ПК по Enter →
  локальная расшифровка whisper.
- `4617e63` — локальная LLM (Qwen2.5-1.5B Q4 через llama.cpp) для пунктуации/
  регистра + A/B-замер WER: полный rewrite ухудшает WER (0.144→0.155),
  режим «только пунктуация» — WER без изменений (0.1443→0.1443). LLM осталась
  в пайплайне с флагом.
- `c06c95c` — **протокол совещания локальной LLM**: summary, темы, решения,
  задачи, ответственные, сроки, вопросы по записи; строгий JSON, валидация +
  retry, chunk/merge для длинных записей, таймкоды у задач/решений,
  null вместо выдуманных данных. 22 теста зелёные (`ml/llm.py`, `ml/prompts.py`).

### Whisper на телефоне (whisper.cpp JNI)

- `545a3fb` — модель base→tiny.

## 2. Мониторинг репозитория

Действуют 2 cron-задачи:
1. **Каждые 10 минут** — проверка GitHub: fetch, новые коммиты в
   main/feature/frontend, прогон тестов при изменениях Python (последняя
   проверка: 204 теста на origin/main — зелёные).
2. **Каждые 3 минуты** — проверка logcat телефона: новый прогон → автоматически
   отчёт run-NNN.md, разбор ошибок, обновление графиков, коммит+push.
