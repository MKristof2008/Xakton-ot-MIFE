# Тестовые аудио для проверки приложения

Файлы в этой папке — пробники для ручного тестирования приложения «Нейро-стенографист»
(импорт аудио -> транскрибация -> диаризация -> экспорт JSON).

| Файл | Язык | Описание |
|---|---|---|
| test_dialog_ru.m4a | русский | Тестовая запись для проверки пайплайна (ASR + диаризация + метки) |

Использование: установить APK, на главном экране «Выбрать файл» и указать этот файл.
Это НЕ эталон для подмены результата — только входные данные для проверки работы модели.
