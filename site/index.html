Нейро-стенографист

Локальное преобразование аудиозаписей в структурированную расшифровку с разделением говорящих. Всё на устройстве, без интернета.

Nuclear IT Hack 2026 Android Kotlin · Compose Офлайн Команда Hex.Team

Что это

Приложение принимает запись разговора из памяти Android-устройства и выдаёт расшифровку: кто говорил, в какое время и что именно. Результат можно посмотреть в приложении и экспортировать в JSON.

Аудиофайл → Распознавание речи → Определение говорящих → Сшивка реплик → Пунктуация → JSON

Все этапы выполняются на устройстве. Приложение не запрашивает разрешение на интернет — это техническая гарантия офлайн-работы, а не обещание.

Формат результата

Структура строго по техническому заданию:

{
  "transcript": [
    {
      "speaker_id": "speaker_1",
      "start_ms": 1250,
      "end_ms": 4380,
      "text": "Добрый день!"
    }
  ]
}

Состояние разработки

Готово

Контракты данных, сшивка ASR и диаризации, экспорт JSON, метрики WER/DER/RTF, интерфейс на Compose, сборка APK.

В работе

Подключение локальных моделей распознавания речи, диаризации и языковой модели вместо заглушек.

Дальше

Замер точности на контрольных записях, оптимизация скорости, обработка шумных записей и перебиваний.

Архитектура

Четыре независимых модуля соединены контрактами. Это позволяет вести разработку параллельно и подменять любую модель без переписывания остального.

Распознавание речи

transcribe(path) → список сегментов с таймкодами в миллисекундах.

Диаризация

diarize(path) → интервалы речи с идентификатором говорящего.

Сшивка

merge(segments, speakers) → реплики «кто, когда, что».

Языковая модель

clean(text) → пунктуация и регистр без изменения смысла.

Ограничения

  • Модели работают полностью на устройстве — качество зависит от модели телефона.
  • Одновременная речь нескольких участников распознаётся хуже, чем последовательная.
  • Сильный фоновый шум снижает точность распознавания.
  • Языковая модель не перефразирует текст: она только расставляет пунктуацию.
