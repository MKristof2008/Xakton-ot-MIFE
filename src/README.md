# Исходный код

Основной продукт — Android-приложение в каталоге `android/`.

| Каталог | Содержимое |
|---|---|
| `android/` | Kotlin, Jetpack Compose, движки моделей |
| `prototype/` | Python-прототип логики (референс поведения, не продукт) |
| `site/` | сайт-витрина проекта |
| `docs/` | архитектура, контракты, ограничения, результаты тестов |

## Android

```
android/app/src/main/java/ru/hexteam/stenograph/
  MainActivity.kt      точка входа
  core/                контракты данных, сшивка, JSON, метрики, пайплайн
  engine/              интерфейсы движков и заглушки
  ui/                  экран и ViewModel
```

Сборка:

```bash
cd android
./gradlew assembleDebug
./gradlew test
```

## Prototype

Python-пайплайн, написанный до перехода на Android. Содержит проработанные промпты
и структуру протокола встречи. Используется как референс: как должна выглядеть
обработка текста и какие правила задавать языковой модели.

**Это не продукт хакатона.** Он использует облачные API, что запрещено ТЗ.
Каталог сохранён для истории и переиспользования промптов в локальной LLM.
