# ТЗ для разработки «Нейро-стенографист» (Hex.team, Nuclear IT Hack 2026)

## Общая задача

Android-приложение: **локальное** преобразование аудио в текст с диаризацией.
**Все вычисления на устройстве, без интернета.**

---

## Архитектура системы

```
[Аудиофайл] → [ASR (Whisper)] → [Диаризация (pyannote)] → [LLM (Gemma)] → [JSON]
     ↓              ↓                      ↓                    ↓
  .mp3/.wav    текст+таймкоды      speaker_id+границы      очистка+связность
```

---

## Компоненты и ТЗ для каждого

### 1. ASR (распознавание речи) — `asr.py`

**Вход:** аудиофайл (mp3, wav, m4a)
**Выход:** `list[dict]` — `[{"start_ms": 1250, "end_ms": 4380, "text": "..."}]`

**Требования:**
- Модель: `faster-whisper` (small или base, локально)
- Язык: русский
- Таймкоды в миллисекундах
- Метрика: WER (Word Error Rate)

**Интерфейс:**
```python

    """Возвращает сегменты с таймкодами."""

```

- Устойчивость к перебиваниям

**Вход:** сырые сегменты с speaker_id

- НЕ перефразировать, сохранять смысл

## Ограничения (жёсткие)

1. ❌ НЕ передавать аудио внешним сервисам
2. ❌ НЕ использовать облачные API
3. ❌ НЕ вычислять на удалённом сервере
4. ❌ НЕ подменять модель заранее подготовленной расшифровкой

✅ Готовые модели и библиотеки — можно.
