# Тестовые аудио

Набор для оценки качества ASR (WER) — 20 записей русской речи из VoxForge:

- `1-20121125-pgp/` — 10 wav (16 кГц, моно) + эталонные транскрипты в `etc/PROMPTS`
- `1981-20120705-haq/` — 10 wav + эталоны

Источник: http://www.repository.voxforge1.org/downloads/Russian/ (лицензия GPL — только для тестов, не для дистрибуции).

## Как считать WER

```
py evaluate_wer.py base
```

Скрипт берёт пары (wav, эталон) из `etc/PROMPTS`, прогоняет через `asr.transcribe` и печатает WER по каждой записи + средний.

## Чего не хватает

- Записи **совещаний с несколькими спикерами** (для диаризации и DER) — VoxForge это одиночная речь. Нужно либо записать свои (2–3 человека, 1–3 минуты), либо взять из открытых наборов (например, CALLHOME / VoxConverse — англ., но для DER язык не важен).
