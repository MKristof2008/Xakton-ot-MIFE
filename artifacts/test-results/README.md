# Замеры на реальном устройстве

Устройство: Samsung Galaxy Z Fold3 (SM-F926B), Android 15, arm64-v8a, 11.6 ГБ RAM.
Сборка: `app-debug.apk` из этого репозитория, модели whisper-base int8 +
pyannote segmentation-3.0 + 3D-Speaker ERes2Net, всё локально, `INTERNET` в манифесте нет.

## Что уже исправлено по ходу замеров

1. `processWithCallback` в sherpa-onnx падает с JNI abort — перешли на `process()`.
2. `Stage.DONE` искался в таблице весов этапов → «Key DONE is missing».
3. Сегменты ASR на границах окон дублировались — добавлено отсечение повторов.
4. **Главное:** текст распознавался целиком и потом делился между спикерами,
   из-за чего слова перемешивались. Порядок изменён на «сначала диаризация,
   потом ASR по каждой реплике» — теперь каждое слово принадлежит своему говорящему.

## Что осталось улучшать

- DER 25 % — диаризация путает часть коротких реплик. Первый кандидат:
  указание числа говорящих вручную (в UI есть) и подбор порога кластеризации.
- На коротких вставках модель иногда выдаёт мусор («P P.») — фильтр по длительности
  уже отсекает часть, нужен фильтр по уверенности.
- Whisper `base` — компромисс скорость/точность; `small` даст меньше WER, но RTF вырастет.
