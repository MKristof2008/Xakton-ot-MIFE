# Результаты тестов

Здесь лежат артефакты замеров качества: файл `results.csv` и контрольные записи.

## Формат results.csv

```
file,duration_sec,processing_sec,rtf,wer,der
```

| Поле | Смысл |
|---|---|
| `file` | имя контрольной записи |
| `duration_sec` | длительность аудио, секунды |
| `processing_sec` | время обработки на устройстве, секунды |
| `rtf` | Real-Time Factor (обработка / длительность) |
| `wer` | Word Error Rate, доля ошибочных слов |
| `der` | Diarization Error Rate, доля неверно размеченного времени |

## Контрольный набор

Требуется три записи по ТЗ:

| Запись | Условия | Назначение |
|---|---|---|
| `clean.wav` | тихая комната, два говорящих | базовый замер WER |
| `noisy.wav` | фоновый шум | проверка устойчивости |
| `overlap.wav` | перебивания, короткие реплики | проверка диаризации |

Эталонные расшифровки хранятся рядом с записями в формате `.txt`.
